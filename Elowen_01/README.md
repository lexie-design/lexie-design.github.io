Assignment 01 - Responsive Navigation -

For this assignment, I created two responsive navigation bars: one demonstrating good design and the other demonstrating terrible/poor navigation design.

For the "good" navigation, I was inspired by Teach Access branding where I currently serve as their UX Intern. I used colors inspired by our actual organizational branding and paired them with the Quicksand font from Google Fonts. I focused on readbility, contrast, spacing, and clear hover and current-page states.

For the bar navigation, I intentionally used poor design choices such as very strong bright and clasing colors like bright red, yellow, and lime. It also uses distracting hover effects, has inconsistent styling, and Comic Sans (which we all know is famous for its terrible usablity).

Both navigation bars were designed mobile-first with a vertical layout. At 769px, a media query changes the navigation to a desktop/horiztonal layout for larget screens.

I referenced the example HTML and CSS files provided in class while also planning and developing my navigation bars. I also referred to numerous online tutorials and resources throughout the development process, particularly when troubleshooting or debugging. I also used a seperate google doc to make notes and map out ideas before transferring them to VSS.
