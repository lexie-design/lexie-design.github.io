Assignment 3: Format something from an API of your choosing (but NOT the temperature / units from the example). 

I opted to do a MSU Admissions Snapshot which displays Michigan State University’s 2025–26 admissions and tuition information. It uses the Open College Data API at https://opencollegedata.org/colleges/michigan-state-university/2025-26.json to retrieve JSON, then JavaScript formats application totals, admissions, admission rate, GPA, ACT range, and tuition as HTML cards.

Data is credited to Open College Data under CC BY 4.0; tuition figures are not the full cost of attendance. AI helped format the project and review the code for errors.
