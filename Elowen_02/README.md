This interactive Taylor Swift Era and Color Customizer was created for Assignment 02 to demonstrate JavaScript event handling and real-time DOM manipulation across three distinct starter files (index.html, css/stylesheet.css, and js/script.js) without requiring full page reloads or external libraries. Inspired by my love for Taylor Swift’s artistry, having helped run the campus Taylor Swift Club during my sophomore year and served as the Undergraduate Teaching Assistant for the inaugural Taylor Swift course offered in ISS last year, the project integrates her full discography alongside The Life of a Showgirl into an engaging web application. Across the interface, four separate interactive form controls dynamically update the document: an album dropdown that alters card styling and lyrics, a text box that renders a live favorite-song badge, a native color picker that provides instant background customization, and a shuffle button that applies randomized color palettes, all while preserving clean separation of concerns. Gemini AI was utilized during development as a technical validation tool to test vanilla JavaScript syntax, verify event listener registration, and ensure that all assignment requirements were met cleanly and accurately.
